# ommisa.github.io

The product page of Ommisa, the OIML SMART assistant.

Ommisa answers questions about OIML publications with clause-level
citations (the public service at [ai.oimlsmart.org](https://ai.oimlsmart.org/))
and assists the operators of the OIML SMART certification platform with
drafts that the operator confirms.

The site is a single static page (`index.html`), served by GitHub Pages
straight from the default branch — there is no build step. All copy
follows the program's writing style (complete sentences, claims grounded
in named entities and numbers, boundaries stated explicitly).
